# Photomosaique
Reconstruction d'une image cible en mosaïque uniforme (une seule image ajustée en couleur) et en vraie photomosaïque (sélection dans une banque d'images), avec comparaison de critères de correspondance et d'espaces colorimétriques (RGB, LAB). Projet réalisé en Python en équipe de 2, cours GIF-4105(Photographie algorithmique).
